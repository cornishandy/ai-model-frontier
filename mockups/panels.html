Option A: a settings sheet with labelled rows

One control per row, bold label on the left, grouped under four headings, with a one-line hint where it helps. It opens from a “Display ▾” button beside the axes and can stay open. Easy to scan, takes more height.

Option B: one row of dropdowns that show their current value

Each setting is a button reading “Labels: Auto ▾”; the menu lists the choices with a one-line explanation each (the same menu style as the axis pickers). Fits in one or two rows at any width, and the current state is readable at a glance. Two clicks to change a setting instead of one.
